PART  II  —  UNIFIED  CHARACTER  
PROGRESSION
 
4.  FOUR  PROGRESSION  CATEGORIES  
Runalis  must  distinguish  four  major  progression  systems:  
1.  Combat  Level.  2.  Core  Attributes.  3.  Combat  Proficiencies.  4.  Individual  Skill  Mastery.  
They  must  interact  coherently  without  becoming  redundant.  
5.  COMBAT  LEVEL  
Combat  Level  represents  overall  character  experience  and  combat  capability.  
Each  enemy  has  a  predetermined  base  XP  value.  
An  enemy  worth  50  XP  grants  a  qualifying  solo  player  50  Combat  XP.  
Combat  Level  must  not  be  calculated  from  the  average  level  of  individual  attributes.  
Combat  Level  advances  independently.  
Combat  Level  affects  all  relevant  combat  abilities  
Even  an  unmastered  skill  must  become  stronger  as  a  character  gains  Combat  Levels.  
For  example:  
A  Combat  Level  30  character  using  a  Mastery  Level  1  spell  should  have  substantially  stronger  
output
 
than
 
a
 
Combat
 
Level
 
1
 
character
 
using
 
the
 
same
 
Mastery
 
Level
 
1
 
spell,
 
assuming
 
equivalent
 
equipment
 
and
 
other
 
relevant
 
statistics.
 
Combat  Level  should  meaningfully  contribute  to:  

--- PAGE 13 ---
●  Weapon  attacks.  ●  Combo  attacks.  ●  Offensive  skills.  ●  Healing.  ●  Defensive  abilities.  ●  Summons.  ●  Damage-over-time  effects.  ●  Appropriate  support  skills.  
However,  effects  must  scale  appropriately  to  their  function.  
Do  not  multiply  durations,  movement  speed,  range,  or  charges  simply  because  an  ability  is  
associated
 
with
 
combat.
 
Combat  Level  provides  overall  strength.  
Proficiency  provides  specialization.  
Mastery  improves  the  individual  skill.  
Equipment  and  Fates  modify  the  final  result.

PART  III  —  UNIVERSAL  SURVIVAL  
DEVELOPMENT
 
9.  HEALTH,  STAMINA,  DEFENCE  AND  SPIRIT  ALWAYS  
LEVEL
 
This  is  mandatory.  
Every  class  must  naturally  develop:  
●  Health.  ●  Stamina.  ●  Defence.  ●  Spirit.  
These  four  attributes  receive  guaranteed  baseline  XP  from  eligible  combat  victories.  
Their  development  must  not  depend  entirely  on  whether  the  player  uses  corresponding  abilities.  
For  example:  
A  pure  physical  character  must  still  improve  Spirit.  
A  pure  spellcaster  must  still  improve  Stamina.  
A  lightly  armored  character  must  still  improve  Defence.  
A  defensive  character  must  still  improve  Health.  
The  rate  may  vary  according  to  meaningful  combat  behavior.  

--- PAGE 17 ---
However,  every  character  should  maintain  functional  development  across  all  four  essential  
survival
 
attributes.
 
These  are  foundational  statistics.  
They  should  not  compete  so  aggressively  for  XP  that  a  normal  character  becomes  
fundamentally
 
dysfunctional.
 
 
PART  IV  —  ADAPTIVE  XP  DISTRIBUTION  
10.  EVERY  ENEMY  HAS  A  PREDETERMINED  XP  VALUE  
Every  enemy  must  define  a  base  Combat  XP  reward.
